自动证据见 [components.md](components.md)。这里只检查机器无法判定的布局、反馈、动画、浅色主题和游戏中呈现；不重复保存/重开/类型校验。自动失败项仍由开发排查，不能由观感检查代替。

- [ ] 缩窄窗口并切换各标签：标签左对齐、控件贴内容，无截断或大面积空白。
- [ ] 切浅色主题，打开候选菜单和提示：文字、焦点、选中态清楚，无遮挡。
