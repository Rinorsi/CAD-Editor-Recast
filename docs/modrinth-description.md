**CAD Editor Recast** is a next-generation rewrite of [CAD Editor](https://modrinth.com/mod/cad-editor), expanding upon the original with broader editing capabilities and live 3D previews.

Press `I` in-game (or run `/cade`) to open the visual editor:
- Hover over an item in your inventory, or hold an item and press `I` → **Edit the item**
- Aim your crosshair at a block, entity, or another player and press `I` → **Edit that target**
- Look at nothing with an empty hand and press `I` → **Edit yourself**

---

### What You Can Edit

**Items**
- Full support for all persistent data components in your running game version (107 / 108 / 119 vanilla components in 26.1.2 / 26.2 / 26.3 respectively, plus custom components registered by other mods).
- **Spawn Eggs & Spawners**: Directly edit mob variants, scale, attributes, status effects, and full equipment.
- **Live Game Data & Previews**: Tooltip previews are generated by the game itself. Numeric ranges and available options are read from the game's actual Codecs and registries rather than hardcoded tables.

**Blocks & Entities in the World** (aim at a target and press `I`, or use `/cadeditor block|entity|player`)
- **Block States & Block Entities**: Containers, signs, banners, beehives, lecterns, jukeboxes, decorated pots, command blocks, heads, and processing progress for furnaces, brewing stands, campfires, and more.
- **Entities**: Armor stand poses (with live pose previews and presets), mob variants, equipment, attributes, item frames and paintings, display entities, villager trades, passenger relationships, and more.

**Local Vault** (press `O`, or open it from the main menu or pause menu)
- Save your customized items locally and retrieve them into inventory slots or item fields. Supports organization, import, and export.

---

### Key Bindings

All key bindings can be changed under **CAD Editor** in the game's Controls settings:
- `I`: Open the editor. Hold `Shift + I` to ignore the crosshair target and edit only the held item, or yourself if your hand is empty.
- `O`: Open the Local Vault.

---

### Installation & Multiplayer (Client Required, Server Optional)

**You can still join and use the mod when it is not installed on the server:**
- **Without Permissions / Normal Survival**: Saving, organizing, and importing/exporting in the Local Vault are unavailable.
- **Creative Mode**: Directly edit and write back items in your own inventory.
- **With Vanilla Command Permissions (OP)**: Edit your own inventory items and pull items from the Vault into your inventory via vanilla commands, as well as individually edit your own game mode, XP level and points within the current level, position and rotation within the current dimension, and the base value of a single syncable attribute (each change sends a single command and is confirmed after reading back from the server).
- **Features Requiring the Server Mod**: Directly editing blocks and entities in the world, editing other players, and modifying self fields that have no direct vanilla command equivalent (such as health, hunger, ability flags, full respawn configuration, and attribute modifiers) require the mod to be installed on the server with permissions granted. The UI indicates these requirements in advance.
