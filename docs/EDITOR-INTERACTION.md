# 编辑、缩放与窗口偏好

界面修改先遵守 [项目界面规范](EDITOR-UI-RULES.md)；项目 Skill 与 AGENTS.md 会将后续界面任务引到同一份约定。

译名与本地文案清单见 [译名审计](LOCALE-AUDIT.md)。实时游戏译名优先于本地回退；游戏模式、装备属性生效位置和有官方键的枚举读取当前语言包。稀有度无原版语言键时回退“常见 / 少见 / 稀有 / 史诗”。NBT 和方块状态标识不改名。

药水和共用效果列表的统一时长、单条时长接受 -1 秒作为永久，保存为 duration:-1，不乘以 20。读取时同样保留 -1；选择窗口旁显示“永久”，效果列表摘要显示“永久”。已有效果的未知字段、隐藏效果及未编辑的时长继续保留。输入普通秒数或关闭永久开关可恢复有限时长。

无方块实体的方块预览直接使用 Oriel 的 block 模型及完整当前方块状态，不要求存在同 ID 物品；修改农作物 age 等状态立即更新预览。已有头颅等特殊物品渲染入口保留。

桶的两条加载路径分别处理：bucket_entity_data 是有限字段的桶标签；同类型 entity_data 会先经 EntityType.updateCustomEntityTag 加载完整实体数据，再执行物种桶加载器。新增实体属性和自定义 SNBT 入口，类型不匹配时不冒充已生效。普通桶生命超限在可计算时联动最大生命属性写入 entity_data，桶生命仍写入 bucket_entity_data；降低上限同步降低超限桶生命，两组件共享一步撤销。硫方怪成长可能重设属性，暂不自动提高其上限。无法联动时仍允许合法 Float 自定义并显示放出限制。刷怪蛋继续使用 entity_data.id 指定种类，并使用原有完整实体表单与生命联动。

上述路径来自三版缓存游戏源码阅读，尚未执行本轮游戏验证。机制参考：https://zh.minecraft.wiki/w/鳕鱼桶 和 https://zh.minecraft.wiki/w/刷怪蛋；后者可能描述较新版本权限规则，实际目标版本以游戏源码为准。

Esc 每次只处理当前最内层：先关闭候选浮层、取消拿起的物品，再返回子窗口或嵌套物品父页，主页面才交给游戏关闭编辑器并返回原背包。设置、详情、保险库等窗口保留打开它们的父窗口及原滚动/焦点；输入框已处理的 Esc 不再冒泡关闭父层。子物品有修改时先询问保存或放弃，Esc 关闭询问表示继续编辑，不会静默丢弃草稿。Editor 页面不触发 Oriel 的三次快速 Esc 强关，Shift+Esc 的紧急退出仍保留；其它 Oriel 页面不变。

设置 → 界面提供独立的编辑器缩放：自动、1、2、3、4。自动跟随游戏 GUI 比例；指定等级由 Oriel 原生视口处理布局、绘制和鼠标命中，不修改游戏全局 GUI 设置。

打开方式可选“记住上次”“默认最大化”“默认窗口化”，下次打开生效。窗口尺寸、侧栏宽度、最近最大化状态、缩放和打开方式由客户端宿主保存到当前实例的 `config/cadeditor-ui.json`。拖动结束立即提交偏好，宿主合并写入并原子替换文件；失败搜索日志中的 `prefs`。

每类物品主标签首位是“物品栈”，首次打开仍选择原来的常规功能页。“物品栈”内部选择命令、物品栈 SNBT 或 JSON，当前会话记住选择。旧“原始数据”“展示命令”及高级 SNBT/命令入口统一进入该页对应分支；高级保留全部组件、改动对比和修改历史。

物品栈 SNBT 在同一个连续多行原生输入框里实时着色并编辑，支持鼠标定位/跨行拖选、剪贴板、撤销与输入法预编辑，不创建第二块只读代码。格式化、压缩、复制、分支选择和 A−/字号/A+ 位于原面包屑工具行，超宽仅该行横滚。字号范围 8～20，默认 12，仅影响代码区域。输入不自动格式化，解析失败保留原文和上次有效草稿；底部状态可展开具体错误，解析器提供位置时点击定位。编辑区右上“重新读取当前草稿”只读取本地草稿，不读取游戏或重置其他字段。命令和 JSON 仍为生成输出，JSON 使用 JSON 词法、保持只读及复制语义；只有 SNBT 分支编辑完整栈。应用到游戏沿用页面应用流程和权限。

实时原生着色需要 Oriel 0.15.x 的 `setTextHighlights`；缺少 API 或参数被拒绝时显示明确错误并写入诊断日志，不能将白色输入框视为着色成功。正式依赖更新须重新打包并重启，页面热更新不升级 Java 引擎。

异步注册表数据返回时，物品栈 SNBT 编辑区保持挂载，不重新创建或移除输入框；焦点、选区、滚动和未完成的原文保留。物品名称及标签仍更新，普通字段页仍刷新注册表选项。该行为不以重新抢焦点或重设文本模拟输入连续性。

在玩家背包、末影箱、容器或收纳袋格子的小窗中选择“编辑物品”，可进入同一套物品组件编辑页，也可继续编辑下一层物品。进入前刷新父世界草稿持久化队列，父文档、历史、展开与滚动位置保留；保存只回填原槽位草稿，最终在父页面应用才提交游戏；取消不改变父草稿。父目标或内容变化、已有写入未结束时禁止重定向提交。是否能把父草稿写回，仍由当前后端和服务器权限决定。

特殊浮点数使用显式 SNBT 类型，例如 `NaNf`、`+Infinityf`、`-Infinityd`。只有实际 Float/Double Codec 允许的值才能应用；整数和真实范围约束仍有效。未带类型后缀的 `Infinity` 按原版字符串解析。严格 JSON 无法表示这些数值，页面传输使用 `null` 投影和精确 SNBT 类型数据共同保真；不要把投影单独当作完整物品导出。

Editor 页的物品 2D/3D 预览通过本项目限定页面范围的解析适配使用同一套特殊浮点 SNBT，不再排除整组属性组件。真实解析失败保留日志并进入底部问题入口，不在模型区增加说明。Oriel 依赖版本保持不变。新建容器里的 typed 子数值也会触发 SNBT 校验和应用，旧 JSON 校验回执不能阻塞这份数据；字段结构尚未返回时不提前判成不支持。界面以 `NaN`、`∞`、`−∞` 显示，输入同时接受英文与无穷符号。

经验等级采用原版非负 int 范围 `0..2147483647`。极高等级会触发游戏自身的升级经验计算溢出，界面另行提示。手输坐标、生命、进度和属性值不再按显示小数位截断；服务器 Codec 和实际存储精度仍生效。仅使用原版命令的经验进度路径按本级整数经验点操作。

写回诊断见 [物品写回日志](INVENTORY-WRITE-DIAGNOSTICS.md)，纯客户端背包能力见 [能力与限制](client-only-hotbar.md)。

多选窗口用于管理当前列表：重新打开时已有条目勾选，确认后新增新选项、移除取消勾选的项；允许全部取消后确认清空。取消或关闭窗口不提交。搜索、分类和分页不清除其他页的勾选；“已选”分类也显示当前注册表尚未返回的已有 ID，仍可移除。再次确认不重复追加已有项，不修改未编辑的等级、时长或未知字段。主动修改统一参数时才更新对应参数；原列表顺序保留，新项追加到末尾。

挖掘规则通过“选择挖掘规则”打开公共多选窗口。搜索框下方同一行提供速度和掉落判定，控件按内容占宽，窄窗口可换行。参数随所选方块或标签一起确认，外层不增加批量工具栏或选择对勾。已有规则的参数默认保持；新规则默认速度 4、正确工具判定。选择“不覆盖判定”会省略该字段，继续按游戏后续规则判断；“非正确工具”不等于所有方块均无掉落。列表在限定高度内滚动，添加入口、耐久损耗和创造模式开关位于列表外。稀有度、附魔光效使用标题右侧下拉框，保留恢复默认和稀有度手动输入。

装生物的桶首次打开“桶内实体”常规页；“物品栈”仍排首位但不自动打开。桶→实体关系读取实际 MobBucketItem 的 EntityType，不从物品 ID 猜测。即使没有 bucket_entity_data，也能显示该桶声明的默认实体；仅浏览不会写入完整实体默认 NBT。常规控件只提供目标版本桶加载确实读取的字段：基础开关和生命，美西螈、蝌蚪共用年龄和年龄锁定，捕猎冷却仅美西螈；26.2/26.3 的硫磺方块桶使用实际加载器的小写 age、age_locked，26.1.2 不展示不存在的该类型。26.1.2 不提供该版桶加载不读的 PersistenceRequired。外观通过游戏专用物品组件和实时 Codec 表单编辑，包括热带鱼图案及颜色、美西螈变体、鲑鱼大小，不使用旧 Variant/BucketVariantTag 替代。未确认加载语义的模组桶明确回退原始数据，未知字段及 typed NBT 保留。保存后还应放出生物核对实际值；表单或独立测试通过不代表这一实机步骤已通过。

桶生命值允许合法自定义 Float，不把放出时的最大生命当作存储硬限制；范围还没读取时也能编辑，不猜物种上限。原版放出时按实际实体最大生命限制，硫磺方块还受体型和成长影响。控件只常驻显示短提示，如 `放出上限 3`、`放出时：100 → 3` 或动态体型的上限区间，机制点击后查看。浏览、失焦和切页不改写导入值；无效数字不写入草稿。未知字段和类型继续保留。桶标签不是完整实体加载，例如额外写入 active_effects 并不使效果生效，名称应使用专用物品组件。
